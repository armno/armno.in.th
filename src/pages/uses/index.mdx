<UseSection id="terminal">
### Terminal: Ghostty & Herdr

I need my terminal app to be 1) fast, 2) reliable, and 3) beautiful at rendering text. [Ghostty](https://ghostty.org/) checks all the boxes.

Inside Ghostty, I use [Herdr](https://herdr.dev/), which is like tmux with modern upgrades. I usually have only 1 terminal window running Herdr.
Everything else lives inside it: spaces, tabs, the agents list.

In both the terminal and the editor, I use [JetBrains Mono](https://www.jetbrains.com/lp/mono/).

</UseSection>

<UseSection id="ai-coding-agent">
### Coding Agent: Claude Code

[Claude Code](https://claude.com/product/claude-code) is what we use as a team at work. I usually use the latest and smartest models available.
I don't have a lot of plugins and skills installed. Only the ones I actually need.

I also like to check out [OpenCode](https://opencode.ai/) from time to time. I like watching how it evolves.
</UseSection>


<UseSection id="diff-tools">
### Diff tool: Hunk

Reviewing changes made by the AI Coding Agent is important. I mainly use [Hunk](https://www.hunk.dev/) to view the Git diffs. Hunk comes with:

- beautiful syntax highlighting
- responsive layouts - display horizontal or vertical diffs automatically based on available space
- the ability to leave code review comments in the diff, so my coding agent can pick them up and fix the issues.

I still reach for plain `git diff` for small changes.
</UseSection>

<UseSection id="code-editor">
### Editor: VSCode & Zed

I still need a code editor to read and make small changes to the code. Currently, my main editor is [VSCode](https://code.visualstudio.com/).

Sometimes I switch to [Zed](https://zed.dev/). Zed is very fast out of the box and keeps getting better. It's just too good to ignore.

I still keep my [Vim setup](https://github.com/armno/dotfiles/blob/main/.vimrc) for quick file editing in the terminal.
</UseSection>

<UseSection id="shell-prompt">
### Shell: Zsh & Starship

I use [Zsh](https://www.zsh.org/) with [Starship](https://starship.rs/) as the prompt.
Some of my favorite CLI tools are:

- [zoxide](https://github.com/ajeetdsouza/zoxide) for fast directory switching (replaces `cd`).
- [fzf](https://github.com/junegunn/fzf) - a command-line fuzzy finder. Many other tools I use are built on top of it.
- [fnm](https://github.com/Schniz/fnm) - fast node (version) manager. If you're still using nvm, try this. You're welcome.
- [eza](https://github.com/eza-community/eza) replaces `ls`.
- [bat](https://github.com/sharkdp/bat) is an upgraded version of the `cat` command.

I keep my [dotfiles repo](https://github.com/armno/dotfiles) maintained.
</UseSection>

<UseSection id="browser">
### Browser: Helium & Chrome

[Helium](https://helium.computer/) is my browser-browser, while [Chrome](https://www.google.com/chrome/) is my dev-browser.

Helium is like a barebones version of Chromium, without all Google stuff. It's fast, minimal, and privacy-focused. It breaks sometimes though.

I use Chrome strictly as a development browser. I let Claude use Chrome via [its MCP](https://claude.com/claude-in-chrome) so it can go nuts with it.
</UseSection>

<UseSection id="graphics">
### Graphics: CleanShot X & Pixelmator Pro

[CleanShot X](https://cleanshot.com/) is one of my favorite Mac apps ever. I use it for:
  - screenshot capturing & annotation
  - screen recordings
  - OCR sometimes

For more serious photo editing, which I do once in a while, I use [Pixelmator Pro](https://en.wikipedia.org/wiki/Pixelmator) - the old version, from before Apple acquired them.
</UseSection>

<UseSection id="productivity-tools">
### Productivity: Raycast & Karabiner-Elements

I use [Raycast](https://www.raycast.com/) as a Spotlight replacement (I wrote about Raycast in ["Things I like about Raycast"](https://armno.in.th/blog/things-i-like-about-raycast/)) with a few extensions.
I heavily use the clipboard history and Bitwarden extensions.

[Karabiner-Elements](https://karabiner-elements.pqrs.org/) allows me to do things quickly with keyboard shortcuts.
It's painful to set up. So I copied the [system from Maximilian Stoiber](https://github.com/mxstbr/karabiner) and adjusted it. Works on both my Corne keyboard and the built-in MacBook keyboard.

</UseSection>

<UseSection id="macbook">
### Computer: MacBook Air M2

It's my work machine from the company. It's a regular M2, upgraded to 16GB of RAM and a 512GB SSD.

When I feel like using an external keyboard, I connect it to my Corne split keyboard (build log here: [Low Profile Wireless Corne Keyboard](https://armno.in.th/blog/low-profile-wireless-corne-keyboard/)).

For a mouse, I use a Ugreen Bluetooth mouse. Nothing special with it except that it is silent, which is all I need from a mouse.
</UseSection>

<UseSection id="monitor">
### Monitor: Samsung 28” UR55 UHD 4K & Monitor Arm

I picked [Samsung UR55](https://www.samsung.com/ie/business/monitors/high-resolution/monitor-ur55-lu28r550uquxen/) because of its IPS panel (and it was on sale). 28 inches is a perfect size for me. Not too big or too small.
I mount it with an NB-F80 monitor arm to gain some space on the desk.
</UseSection>

<UseSection id="headphones">
### Headphones: Sony XM4 & AirPods 4

My main headphones are the [Sony WH-1000XM4](https://www.sony.co.th/en/electronics/support/wireless-headphones-bluetooth-headphones/wh-1000xm4/specifications) and the [AirPods 4 ANC](https://www.apple.com/airpods-4/). The XM4s are for music listening. The AirPods are for everything else.

Both have great active noise-cancelling, which I cannot live without these days.
</UseSection>

<UseSection id="alumni">

### Alumni

Things I enjoyed using in the past, but are no longer in my current setup.

- [iTerm2](https://iterm2.com/) - my go-to terminal app for many years. Replaced by Ghostty.
- [Kitty](https://github.com/kovidgoyal/kitty) - another GPU-accelerated terminal app. Fast, but its text rendering never looked as good to me.
- [Arc](https://arc.net/) - was my main browser for quite a while.
- [Cursor](https://cursor.com/) - replaced by Claude Code + VSCode.
- [1Password](https://1password.com/) - I was a big fan until they bumped up the price. It is too expensive for me.
- [delta](https://github.com/dandavison/delta) - a terminal diff tool.
</UseSection>
