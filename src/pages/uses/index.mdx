<UseSection id="terminal">
### Terminal: Ghostty & herdr

I need my terminal app to be fast, reliable, and display text beautifully. Ghostty checkes all the boxes.

Inside of Ghostty, I use herdr, which is like tmux with agentic coding upgrades. I usually have only 1 terminal window running herdr.
Everything else lives inside herdr: spaces, tabs, agents list.
</UseSection>

<UseSection id="ai-coding-agent">
### Coding Agent: Claude Code

The AI Coding Agent we use at work as a team. I usually use the latest models available.
I don't have a lot of plugins and skills installed. Only ones that are needed for work.

I also like to check out OpenCode from time to time. I like to see how it gets developed and how it improves.
</UseSection>


<UseSection id="diff-tools">
### Diff tools: Hunk

Reviewing changes made by the AI Coding Agent is important. I use hunk to see the diffs with syntax highlighting, responsive layouts, and ability to put code review comments in the diff so that my coding agent can pick up and fix the issues.
I still keep the default `git diff` command available when reviewing small changes.
</UseSection>

<UseSection id="code-editor">
### Editor: VSCode & Zed

I rarely code by hand these days, but I still need a code editor to read the code. Currenly, it's VSCode with my basic setup.

I sometimes switch to Cursor or Zed. Cursor used to be my main editor for a while before we move things over to Claude Code.
And Zed is just too good to ignore.
</UseSection>

<UseSection id="shell-prompt">
### Shell: Zsh and Starship

I use zsh (which is now the default shell in MacOS) with Starship is a prompt.

Paired with JetBrains Mono fonts for both in the terminal and in the code editor.
</UseSection>

<UseSection id="browser">
### Browser: Helium & Chrome

Helium is my browser-browser, while Chrome is my dev-browser, which is also used by Claude via its Chrome MCP.

Helium is like a barebone version of Chromium, without all Google stuffs. It's fast, minimal, and privacy-focused.
</UseSection>

<UseSection id="images">
### Images: Cleanshot X, Pixelmator Pro, and imageoptim

I use Cleanshot X many times a day to capture screenshots and annotate them. Then I usually use Imageoptim to reduce the file size.

For more serious photo editing, I use Pixelmator Pro.
</UseSection>

<UseSection id="productivity-tools">
### Raycasts, Karabiner Elements

I use Raycasts as Spotlight replacement (I wrote about Raycasts in "Things I like about Raycasts") with a few extensions.
I heavily use clipboard history and Bitwarden extensions.

Karabiner Elements allow me to do things quickly with keyboard shortcuts.
I copied the system from Maximilian Stoiber and adjust to my own preferences.

</UseSection>

<UseSection id="macbook">
### Computer: Macbook Air M2

It's a work equipment from the company. It's been working well until today.
</UseSection>

<UseSection id="monitor">
### Monitor: Samsung 28” UR55 UHD 4K & NB-F80 Monitor Arm

I think I picked this monitor just because of its IPS panel. 28 inches is a perfect size for me. Not too big or too small.
I mount it with a monitor arm to gain some space on the desk.

</UseSection>
