Inspired by [uses.tech](https://uses.tech) where developers share their hardware, software and tools they use regularly. Here are my tools.

## Software

<UseSection id="terminal">
### Terminal

I use [Ghostty](https://ghostty.org/) with:

* [zsh](https://www.zsh.org/) and [Starship](https://starship.rs/) prompt
* [base16-shell](https://github.com/chriskempson/base16-shell) for terminal colors
* [zoxide](https://github.com/ajeetdsouza/zoxide) as a replacement for `cd` command
* [eza](https://github.com/eza-community/eza) as a replacement for `ls` command
* [bat](https://github.com/sharkdp/bat) as a replacement for `cat` command
* [fnm](https://github.com/Schniz/fnm) for node version management
* and here are my [dotfiles](https://github.com/armno/dotfiles) repo
</UseSection>

<UseSection id="code-editor">
### Code editor

* [Cursor](https://www.cursor.com/) with the official [GitHub](https://github.com/primer/github-vscode-theme) themes (both dark and light, depending on the surrounding light)
* I wrote a blog post about my setup: [My VSCode setup for 2023](https://armno.in.th/blog/vscode-setup-2023/) — most of it applies to Cursor too
* [Vim](https://www.vim.org/) for quick file editing from the terminal, with [vim-plug](https://github.com/junegunn/vim-plug) as the plugin manager. Here is my [`.vimrc`](https://github.com/armno/dotfiles/blob/master/.vimrc).
* Git: command line with [delta](https://github.com/dandavison/delta) to render diffs and logs
* [JetBrains Mono](https://www.jetbrains.com/lp/mono/) fonts in both code editors and terminal
</UseSection>

### Others

* [Homebrew](https://brew.sh/) package manager
* [Arc](https://arc.net/) as the default browser, and [Chrome Canary](https://www.google.com/chrome/canary/) for development
* [Raycast](https://www.raycast.com/) as a Spotlight replacement, calculator, shortcuts launcher, etc.
* [Karabiner Elements](https://karabiner-elements.pqrs.org/) for keyboard shortcut customizations
* [Rectangle](https://rectangleapp.com/) for window management
* [Ice](https://github.com/jordanbaird/Ice) to show/hide icons on the menu bar
* [Pixelmator Pro](https://www.pixelmator.com/pro/) for image/photo editing
* [Cleanshot X](https://cleanshot.com/) to capture and annotate screenshots and screen recordings
* [1Password](https://1password.com/) for password management
* [Google Photos](https://www.google.com/photos/about/) to back up all of my photos

### Alumni

Things I used in the past that are worth mentioning.

* [iTerm2](https://iterm2.com/) — my main terminal app for 10+ years
* [oh-my-zsh](https://ohmyz.sh/) and [oh-my-posh](https://ohmyposh.dev/) — zsh frameworks
* [z](https://github.com/rupa/z) — replaced by zoxide
* [kitty](https://sw.kovidgoyal.net/kitty/) — GPU-accelerated, much faster than iTerm. The only thing that stopped me was that it doesn't render text as beautifully, probably because of the lack of [sub-pixel antialiasing](https://github.com/kovidgoyal/kitty/issues/214).
* [Alfred](https://www.alfredapp.com/) — used it for many years until I found Raycast. Thanks Alfred!
* [BetterTouchTool](https://folivora.ai/) for shortcuts and automation
